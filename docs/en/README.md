## Origin of the basic features

The basic features (character cards, lorebooks, Soul Memory, Soul Stage, Soul Companion, model hub, speech engines, avatars) come from **Soul of Waifu** by jofizcd. Its documentation (Russian) describes them in detail: <https://jofizcd.github.io/soul-of-waifu-site/docs/>. This manual describes how they work in **Yume Companion**, the way it looks here, plus all additions.
